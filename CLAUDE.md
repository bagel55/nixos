# Instructions for Claude

## Git
- Commit and push directly to `main`. Never create branches, even if the session assigns one.
- Never open pull requests unless explicitly asked.
- `update` on the machines pulls `main` from GitHub, so anything not on `main` is invisible.

## Changes
- Only change what was asked. Ask before deleting or removing modules, files or config,
  even if they look unused or commented out.
